Forward kinematics

T₀⁶ = A₁(θ₁) · A₂(θ₂) · · · A₆(θ₆)

Expand the DH transform
Aᵢ = ⎡ cθ   −sθcα   sθsα   acθ ⎤
⎢ sθ   cθcα   −cθsα   asθ ⎥
⎢ 0     sα      cα      d ⎥
⎣ 0     0      0     1 ⎦

cθ = cos θᵢ, sθ = sin θᵢ, cα = cos αᵢ, and sα = sin αᵢ. Multiply transforms from base to tool.

05 / REFERENCE

Plain-language glossary

A quick guide to the terms above. The model and calculations stay first; use this when you want a simpler explanation.

Kinematics
The geometry of how an arm moves. Here, position is calculated from joint angles and link sizes—not from forces or motor power.
Degree of freedom
One independent way the arm can move. This arm has six rotary joints, so six angle values describe its pose.
Joint & link
A joint is a rotating connection; a link is the rigid segment between joints. The servos turn the joints, and the links carry the motion.
Servo angle (θ)
The commanded turn from a joint’s zero reference, measured here in degrees. A real servo may need its zero and travel calibrated.
Coordinate frame
A local set of X, Y, and Z directions—like a tiny ruler attached to the base or a joint. Frame origins are reported in base coordinates.
D-H parameters
Four values that describe each step between frames: θ turns about Z, d shifts along Z, a shifts along X, and α twists about X. In this model, θ changes as you move a control.
Transform matrix
A 4 × 4 table that stores a frame’s rotation and position together. Multiplying the six joint transforms carries the base frame out to the tool.
Forward kinematics
The calculation that uses the six servo angles and known link dimensions to predict where the tool is and which way it points.
TCP / end effector
The tool-center point is the chosen endpoint of the gripper. The readout gives its position relative to the base, plus its orientation.
RPY (ZYX)
Roll, pitch, and yaw are three angles used to describe orientation. This readout uses the ZYX rotation order shown beside it.
Rigid-link assumption
The model treats every link as perfectly stiff and each joint as exact. Real arms can flex, have backlash, or miss a command slightly.
